# Motion design review rubric

Use this checklist with the rendered video and its styleframes. Mark each item **Pass**, **Review**, or **Fail**. A machine check can flag measurable problems; a person must judge story clarity and visual quality.

| Area | Review question |
| --- | --- |
| Continuity | Do palette, light, texture, and recurring visual motifs feel like one visual world? |
| Scene-specific imagery | Does each scene show imagery that helps explain its subject? |
| Focal clarity | Can a viewer identify the main visual point at a glance? |
| Text load | Can the viewer read the text in time, without duplicate narration or captions? |
| Motion purpose | Does motion reveal, connect, compare, transform, emphasize, or settle an idea? |
| Chart accuracy | Are labels, units, scales, and source data correct? Are conceptual diagrams clearly labeled? |
| Caption timing | Do captions match speech and stay readable without covering the focal visual? |
| Sound | Are narration, music, and effects clear, balanced, and aligned to the visuals? |
| Render quality | Are there blur, cropping, flicker, missing assets, or transition artifacts? |
