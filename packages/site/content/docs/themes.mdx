---
title: Themes
description: Set one theme attribute. Look up theme ids without loading previews.
---

Set **one** `theme` on `<video>`. Velox applies type, surfaces, caption bars, and the default background to every scene.

```xml
<video theme="raycast" size="portrait" fps="30" background="theme.canvas">
  <scene template="centerCard" duration="6" background="theme.canvas">
    <hero slot="center" title="Your headline." subtitle="Proof line." />
  </scene>
</video>
```

Use `color="theme.text"`, `theme.muted`, and `theme.accent` on children. The same ids come from `velox list themes`.
