# Rendering

Velox renders **frame by frame** on the server using `@napi-rs/canvas`, then encodes with a native H.264 or GIF encoder. There is no browser capture, no Puppeteer, and no GPU farm requirement.

## Pipeline

1. **Compile** — VML or TypeScript resolves to a typed `VideoConfig`.
2. **Preload** — Images, fonts, and stock assets load before the frame loop.
3. **Draw** — Each frame runs layout, motion, transitions, and captions.
4. **Encode** — Frames stream into `h264-mp4-encoder` (or GIF / PNG sequence).
5. **Mux audio** — Optional music + SFX merged onto the silent video track.

```bash
velox render reel.vml -o out/reel.mp4
```

## Output formats

| Flag | Format | Use case |
|------|--------|----------|
| `-f mp4` (default) | H.264 MP4 | Delivery, social, ads |
| `-f gif` | Animated GIF | Lightweight previews |
| `-f png-sequence` | Numbered PNGs | Further compositing |

## Quality and speed

| Flag | Effect |
|------|--------|
| `--draft` | ~50% resolution, fps capped — fastest sanity check |
| `--scale 0.5` | Explicit resolution multiplier (0.25–1) |
| `--fps 24` | Export at lower fps (duration unchanged, frames dropped) |
| `-q 80` | Encoder quality 0–100 (default 80) |

For iteration, use `--draft` first; ship final exports at full scale without `--draft`.

## Determinism

- Same VML + same asset files → same pixels (no `Date.now()` in scene logic).
- Pin `-o` paths in scripts so CI artifacts land predictably.
- Theme and transition choices are fully declarative.

## Audio

Velox exports **silent video** first, then muxes audio in a second pass.

### Background music

```xml
<video music="track.mp3" musicVolume="0.35">
  ...
</video>
```

Or:

```xml
<video>
  <audio src="track.mp3" volume="0.35" />
  ...
</video>
```

### Sound effects

```xml
<scene duration="5">
  <sfx name="whoosh" at="0.4" volume="0.85" />
  <sfx src="custom.wav" at="2.1" />
</scene>
```

Resolution order for `name="whoosh"`:

1. `./sfx/whoosh.mp3` or `.wav` beside the VML
2. Bundled assets inside the `velox-video` package

### ffmpeg

Audio mux uses ffmpeg. Velox tries **system ffmpeg on PATH** first, then falls back to the **bundled `ffmpeg-static`** binary shipped with `velox-video` — no separate install required for most users.

If both are missing, the video still renders **silent** and the CLI logs a warning.

## Transitions during render

Scene transitions are rendered in the overlap window at the end of each scene. See [Transitions](/docs/transitions) for types and timing rules.

## Troubleshooting

| Symptom | Likely cause |
|---------|----------------|
| Black rectangles on cards | Usually a draw bug — update `velox-video`; report with `reel.vml` |
| Stretched output | Wrong `size` on `<video>` — use `portrait`, `1080p`, `9:16`, etc. |
| Audio missing | Music path wrong, or mux failed — check CLI warnings |
| Lint passes, render fails | Missing image/font asset referenced in markup |
| Slow render | Use `--draft`; reduce scene count; lower `--fps` for previews |
