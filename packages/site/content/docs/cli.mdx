# CLI

Install globally or as a dev dependency:

```bash
pnpm add -D velox-video
pnpm velox --help
```

## Commands

### `velox new <name>`

Scaffold a TypeScript starter project.

```bash
velox new my-video -t product-launch
```

Templates: `news-intro`, `product-launch`, `data-story`.

### `velox preview <file>`

Opens **Velox Studio** with hot reload. Works with `.vml` and `.ts` entry files.

```bash
velox preview reel.vml
```

### `velox render <file>`

Export video to disk.

```bash
velox render reel.vml -o out/reel.mp4
velox render reel.vml --draft
velox render reel.vml -f gif -o preview.gif
velox render reel.vml --scale 0.5 --fps 24
```

| Option | Description |
|--------|-------------|
| `-o, --output <path>` | Output file path |
| `-f, --format <fmt>` | `mp4` · `gif` · `png-sequence` |
| `-q, --quality <n>` | 0–100 encoder quality |
| `--draft` | Fast low-res export |
| `--scale <n>` | Resolution multiplier 0.25–1 |
| `--fps <n>` | Cap export frame rate |

### `velox lint <file>`

Validate VML before spending render time.

```bash
velox lint reel.vml
velox lint reel.vml --strict
velox lint reel.vml --frames   # hints for spot-frame checks
```

### `velox list <type>`

```bash
velox list themes       # all theme="…" ids
velox list blocks       # catalog block ids
velox list animations   # motion primitives
velox list templates    # velox new starters
```

### `velox add <block>`

Copy a catalog snippet into `./blocks` for paste-in use.

```bash
velox add code-typing
velox add stat-counter -d snippets
```

## Recommended workflow

```bash
velox lint reel.vml --strict
velox render reel.vml --draft -o out/draft.mp4
velox render reel.vml -o out/final.mp4
```

## Environment variables

| Variable | Purpose |
|----------|---------|
| `VELOX_*` | Template variables in markup (`{{productName}}` → `VELOX_PRODUCTNAME`) |
| Stock API keys | See markup compiler docs for Pexels/Unsplash providers |

Keep secrets out of committed VML — inject via env in CI.

## What to avoid

- Rendering before lint on LLM-generated markup
- Hard-coded absolute paths to assets — use relative `music="track.mp3"`
- Mixing multiple `theme` values — one root theme per `<video>`
