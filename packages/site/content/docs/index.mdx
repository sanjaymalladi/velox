Velox is a code-first motion engine. You write a reel in Velox Markup, lint it, and export MP4 without a browser capture step.

## Minimal reel

```xml
<video size="portrait" fps="30" theme="stripe" motionQuality="premium">
  <scene duration="5" template="centerCard" camera="slowPush"
         transition="blurDissolve" transitionDuration="0.6">
    <hero slot="center" kicker="INTRO" title="Ship faster." subtitle="Native render, no capture." />
    <captions slot="caption" text="One line of proof." style="pill" start="0.5" />
  </scene>
</video>
```

## Start here

- [Your first reel](/docs/getting-started) — install, lint, render
- [Themes](/docs/themes) — one `theme` attribute, then the id list
