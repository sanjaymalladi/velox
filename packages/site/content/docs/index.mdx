# Velox Docs

Velox is an LLM-friendly motion graphics engine for projects that need fast previewing, native rendering, and a lightweight workflow. It lets you create videos from VML or TypeScript and export H.264 MP4, GIF, or PNG sequence output without Chrome, Puppeteer, or FFmpeg.

## What Velox Does

Velox provides a comprehensive solution for creating motion graphics programmatically:

### Core Capabilities
- **VML-first generation**: XML-like markup gives LLMs a safe, expressive surface for video generation
- **Programmatic animation**: Define scenes in TypeScript when you need low-level control
- **Premium motion**: Scene cameras, blur dissolves, vignette/grain overlays, and Popmotion-backed easing
- **Data and organic visuals**: D3-backed charts and Flubber-backed morph blobs
- **Reel production**: VML templates, semantic announcement components, captions, transparent assets, generated cards, and stock/media placeholders
- **Free-first providers**: generated/local media first, no-key refs where possible, cached before render
- **Fast preview**: Built-in preview studio for rapid iteration
- **Native export**: Canvas + WASM/native encoders instead of browser automation

### Use Cases
- Complex data visualizations and charts
- Animated infographics and explainer videos
- Text animations and kinetic typography
- Particle systems and generative art
- UI animations and micro-interactions
- Short-form announcements, launch videos, tech reels, and social explainers

## Templates

Pre-made templates to get you started quickly:

| Template | Description | Use Case |
|----------|-------------|----------|
| `intro-video` | Animated title sequence | Opening intros, product reveals |
| `data-story` | Chart and data visualization | Infographics, analytics reports |
| `text-kinetic` | Kinetic typography animation | Explainer videos, quotes |
| `particle-system` | Generative particle effects | Backgrounds, ambient animations |
| `product-showcase` | Product feature highlight | Marketing content, demos |

### Using Templates

```bash
# Create from template
npx velox-video new my-project --template intro-video

# Or copy and modify
cp templates/intro-video.ts src/index.ts
```

## Recommended LLM Prompt

Use Velox Markup as the model-facing format:

```xml
<video size="portrait" fps="60" theme="creamChecks" background="creamGrid" motionQuality="premium">
  <scene duration="4.8" template="topTextBottomVisual" camera="slowPush" mood="editorial" transition="blurDissolve">
    <announcement slot="top" title="Launch reels from markup" subtitle="Templates, captions, assets, cards, and beats." badge="NEW" motion="heroCinematic" />
    <asset slot="visual" name="phone-frame" width="360" height="640" motion="driftIn" />
    <captions slot="caption" text="Safe markup, premium motion." style="karaoke" />
  </scene>
</video>
```
