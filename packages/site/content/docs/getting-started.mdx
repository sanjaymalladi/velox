# Getting Started

Velox makes it easy to create professional motion graphics programmatically. Follow these steps to get up and running quickly.

## Installation

### CLI + Core

```bash
npm install -D velox-video @velox-video/core
# or
pnpm add -D velox-video @velox-video/core
```

You can also run the CLI directly with `npx velox-video`.

## Create Your First Video

Create `video.ts`:

```typescript
import { createVideoFromMarkup } from '@velox-video/core'

export default createVideoFromMarkup(`
<video size="portrait" fps="60" theme="creamChecks" background="creamGrid" motionQuality="premium">
  <scene duration="4.8" template="topTextBottomVisual" camera="slowPush" mood="editorial" transition="blurDissolve">
    <announcement slot="top" title="Your first Velox reel" subtitle="VML is safe for LLMs and easy to edit." badge="HELLO" motion="heroCinematic" />
    <asset slot="visual" name="phone-frame" width="360" height="640" motion="driftIn" />
    <captions slot="caption" text="Your first Velox reel is just markup." style="karaoke" />
  </scene>
</video>
`)
```

You can also skip TypeScript and create `reel.vml` directly:

```xml
<video size="portrait" fps="60" theme="creamChecks" background="creamGrid" motionQuality="premium">
  <scene duration="5" template="headlineThenProof" background="warmPaper" camera="slowPush" mood="editorial">
    <breakingNews slot="top" headline="No-key media starts free-first" ticker="Generated fallback, local, Wikipedia, Unsplash Source, OpenBrand metadata." tone="warning" />
    <githubRepo slot="visual" owner="sanjaymalladi" repo="velox" motion="driftIn" />
    <captions slot="caption" text="Generated cards render before export and cache locally." style="highlightKeywords" />
  </scene>
</video>
```

### 2. Preview Your Animation

Run the local studio against your project:

```bash
npx velox-video preview video.ts
# or
npx velox-video preview reel.vml
```

This will start a development server with Hot Module Replacement (HMR). Any changes you make to your animation code will be automatically reflected in the preview.

**Studio Features:**
- Real-time preview with HMR
- Playback controls (play, pause, stop)
- Speed adjustment (0.1x to 4x)
- Frame-by-frame navigation
- Console logging
- Performance metrics

### 3. Render Your Video

Export your project to a high-quality video file:

```bash
# Render with default settings
npx velox-video render video.ts --output my-animation.mp4
# or
npx velox-video render reel.vml --output my-animation.mp4

# Render with high quality
npx velox-video render video.ts --quality high --output my-animation.mp4

# Render to GIF
npx velox-video render video.ts --format gif --output animation.gif
```

## Common Commands

| Command | Description | Example |
|---------|-------------|---------|
| `velox-video new <name>` | Create a new project | `velox-video new intro-video` |
| `velox-video preview <file>` | Start development preview | `velox-video preview src/index.ts` |
| `velox-video render <file>` | Render to MP4 (default) | `velox-video render src/index.ts` |
| `velox-video render <file> --output out.mp4` | Custom output path | `velox-video render src/index.ts --output final.mp4` |
| `velox-video render <file> --format gif` | Render to GIF | `velox-video render src/index.ts --format gif` |
| `velox-video render <file> --quality high` | High quality render | `velox-video render src/index.ts --quality high` |
| `velox-video studio` | Start studio without file | `velox-video studio` |

## Reel Features To Try

- Use `template="topTextBottomVisual"` or `template="headlineThenProof"` on scenes.
- Add `slot="top|visual|caption|overlay"` to important children.
- Use semantic tags like `<announcement>`, `<breakingNews>`, `<ranking>`, `<finalCTA>`.
- Add captions with `<captions text="..." style="karaoke" />`.
- Use generated cards like `<githubRepo owner="..." repo="..." />` or `<npmPackage name="..." />`.
- Add timeline metadata with `<sfx name="pop" at="0.4" />` and `<beat at="1.0" />`. MP4 audio muxing is staged; current exports are silent.
