This guide walks through a **VML reel** — the fastest path for product videos and LLM-generated motion graphics.

## Prerequisites

- **Node.js 18+**
- **pnpm** (recommended) or npm

System ffmpeg is optional — Velox bundles a static binary for audio mux when you install `velox-video`.

## Install

```bash
pnpm create velox-video@latest my-reel
cd my-reel
pnpm install
```

Or add the CLI to an existing repo:

```bash
pnpm add -D velox-video
```

## Project layout

```
my-reel/
  reel.vml          # your markup (primary entry)
  sfx/              # optional whoosh.mp3, click.wav, …
  track.mp3         # optional background music
  out/              # rendered exports
```

TypeScript projects use `video.ts` instead of `.vml` — same CLI commands, different file extension.

## Your first reel

Create `reel.vml`:

```xml
<video size="portrait" fps="30" theme="apple" motionQuality="premium">
  <scene duration="6" template="centerCard" camera="slowPush"
         transition="blurDissolve" transitionDuration="0.5">
    <hero slot="center"
          kicker="VELOX"
          title="Motion graphics from markup."
          subtitle="Lint, preview, render — one toolchain."
          motion="heroCinematic" />
    <captions slot="caption" text="Short caption line." style="pill" start="0.6" />
  </scene>
  <scene duration="5" template="centerCard" transition="wipe">
  <finalCTA slot="center" title="velox render reel.vml" subtitle="That's the whole loop." />
  </scene>
</video>
```

## Lint before render

```bash
velox lint reel.vml
velox lint reel.vml --strict   # warnings fail the command
```

Lint catches invalid tags, bad transition timing, missing `slot` attributes, and unknown theme ids.

## Render

```bash
velox render reel.vml -o out/reel.mp4
velox render reel.vml --draft    # half resolution, capped fps — quick review
```

Progress prints in-place; the output path is deterministic when you pass `-o`.

The usual loop is lint, a draft, then the final file:

```bash
velox lint reel.vml --strict
velox render reel.vml --draft -o out/draft.mp4
velox render reel.vml -o out/final.mp4
```

If elements stack in the center, set `template` on `<scene>` and `slot` on each child. If lint rejects a transition, `transitionDuration` must be shorter than the scene `duration`.

## Add music and SFX

```xml
<video music="track.mp3" musicVolume="0.35">
  <scene duration="5">
    <sfx name="whoosh" at="0.3" volume="0.8" />
  </scene>
</video>
```

Drop `sfx/whoosh.mp3` next to the VML file. See [Rendering → Audio](/docs/rendering#audio) for mux details.

If the export is silent, check that `track.mp3` exists and read the render log for the mux step. Color comes from one `theme` on `<video>` plus `color="theme.text"` on children.
